协议特性
--------
1. Shadowsocks (第1个端口)
   - 加密方式: chacha20-ietf-poly1305
   - 密码生成: UUID 前三段去掉分隔符，共 16 个十六进制字符
   
2. VLESS Reality (第2-5个端口)
   - 协议: VLESS + Reality + XHTTP
   - TLS 指纹: 奇数端口=firefox, 偶数端口=safari
   - Short ID: 8个预设池随机选择
   - SNI/Dest: 3个游戏域名随机选择
   - XHTTP 路径: 默认 /api/v1

部署流程
--------
1. 上传工具到 GitHub 仓库
2. VPS 上下载脚本:
   sudo install -d -m 755 /opt/xhttp-real-deploy
   sudo curl -fsSL https://raw.githubusercontent.com/USER/REPO/main/deploy.sh \
        -o /opt/xhttp-real-deploy/deploy.sh
   sudo curl -fsSL https://raw.githubusercontent.com/USER/REPO/main/runtime-versions.sh \
        -o /opt/xhttp-real-deploy/runtime-versions.sh
   sudo curl -fsSL https://raw.githubusercontent.com/USER/REPO/main/uninstall.sh \
        -o /opt/xhttp-real-deploy/uninstall.sh
   sudo curl -fsSL https://raw.githubusercontent.com/USER/REPO/main/update.sh \
        -o /opt/xhttp-real-deploy/update.sh
3. 执行部署:
   sudo bash /opt/xhttp-real-deploy/deploy.sh
